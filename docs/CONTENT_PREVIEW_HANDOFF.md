# 콘텐츠 미리보기 모달 인수인계

이 문서는 이미지와 긴 코멘트를 함께 가진 메모의 상세 미리보기 동작과 유지보수 경계를 설명합니다. API 키, OAuth 식별자, 계정 ID, Worker URL 또는 암호화 키의 실제 값은 기록하지 않습니다.

## 사용자 동작

- 이미지와 긴 코멘트가 함께 있으면 이미지 캐러셀이 먼저 표시됩니다.
- 같은 모달 내부를 아래로 스크롤하면 코멘트 텍스트 뷰어가 이어서 표시됩니다.
- 이미지가 여러 장이면 이전·다음 버튼, 현재 위치 표시, 모바일 좌우 스와이프를 사용할 수 있습니다.
- 이미지만 있으면 캐러셀만, 긴 코멘트만 있으면 텍스트 뷰어만 표시됩니다.
- 코멘트의 줄바꿈은 유지하며 긴 한 줄은 모달 너비 안에서 자동으로 줄바꿈합니다.

## 계층별 책임

### 화면 계층

- `index.html`: `previewContent` 안에서 `previewImageStage`를 `previewTextStage`보다 먼저 배치합니다.
- `styles/memos.css`: 모달 높이, 세로 스크롤, 코멘트 줄바꿈 및 다크 모드 표현을 담당합니다.
- `index.css`: 이미지 캐러셀의 크기, 버튼, 카운터와 모바일 크기를 담당합니다.

### 처리 계층

- `src/presentation/app-controller.js`의 `showContentPreview()`가 이미지와 텍스트 영역을 독립적으로 표시하거나 숨깁니다.
- `loadPreviewImage()`, `moveCarousel()`, 포인터 이벤트는 이미지 로딩, 이전·다음 이동과 스와이프를 담당합니다.
- 이미지와 코멘트를 탭으로 전환하는 상태는 사용하지 않습니다.

### 핵심 규칙 계층

- `src/domain/memos/memo-policy.js`의 `getMemoPreviewKind()`가 `image`, `text`, `combined`, `none`을 판정합니다.
- 긴 코멘트 판정 기준과 이미지 첨부 개수 규칙은 화면 구현과 분리되어 있습니다.

### 저장 및 외부 서비스 계층

- IndexedDB 이미지 Blob, Google Drive 백업·복구, 메모 저장 형식은 이 모달 변경의 대상이 아닙니다.
- 프레젠테이션 계층은 기존 `driveImageService.loadImage()` 결과만 화면에 표시합니다.

### 의존성 연결 및 앱 시작 계층

- 모달 DOM 참조와 이벤트 연결은 `app-controller.js` 초기화 구간에서 한 번만 설정합니다.
- 제거된 탭 요소나 `setPreviewMode()` 같은 전환 코드를 다시 추가하지 않습니다.

## 회귀 검증

`tests/content-preview-contract.test.js`는 다음 계약을 확인합니다.

1. 이미지 영역이 코멘트 영역보다 먼저 위치합니다.
2. 탭 요소와 탭 전환 코드가 존재하지 않습니다.
3. 이미지와 코멘트 영역을 각각 표시할 수 있습니다.
4. 모달은 세로로 스크롤되고 긴 코멘트가 가로로 넘치지 않습니다.

기능 변경 후에는 전체 테스트와 빌드 외에도 모바일 및 데스크톱에서 이미지 1장, 이미지 여러 장, 긴 코멘트 단독, 이미지와 긴 코멘트 조합을 직접 확인합니다.
