# 코멘트 표시 정책 인수인계

이 문서는 링크 카드의 코멘트 표시 규칙과 이미지·텍스트 미리보기 연결을 설명합니다. 실제 계정, Firebase·Google·Cloudflare 식별자, OAuth 토큰, API 키 및 암호화 키는 이 문서나 로그에 기록하지 않습니다.

## 목적

카드에 긴 코멘트가 항상 노출되어 목록이 과도하게 길어지는 문제를 해결하면서 짧은 코멘트의 즉시 확인, 링크 이동, 이미지 캐러셀, 이미지별 삭제와 통합 모달을 유지합니다.

## 핵심 규칙

논리적 줄 수는 `src/domain/memos/memo-policy.js`에서 계산합니다.

- CRLF와 CR은 LF로 정규화합니다.
- 앞뒤 공백을 제거한 뒤 명시적인 줄바꿈으로 나눕니다.
- 중간의 빈 줄도 사용자가 입력한 줄로 계산합니다.
- 화면 폭 때문에 자동 줄바꿈된 시각적 줄은 논리적 줄 수에 포함하지 않습니다.
- 코멘트가 없으면 `none`입니다.
- 1줄 또는 2줄이면 `inline`입니다.
- 3줄 이상이고 이미지가 없으면 `accordion`입니다.
- 3줄 이상이고 이미지가 있으면 `modal-only`입니다.

`getCommentDisplayMode(item)`이 위 네 상태 중 하나만 반환합니다. 화면 코드는 자체적으로 줄 수를 다시 판정하지 않습니다.

## 미리보기 규칙

`getMemoPreviewKind(item)`은 저장 여부가 아닌 미리보기 내용만 결정합니다.

- 이미지와 코멘트가 함께 있으면 코멘트 길이와 관계없이 `combined`입니다.
- 이미지 없이 3줄 이상의 코멘트가 있으면 `text`입니다.
- 이미지만 있으면 `image`입니다.
- 그 밖에는 `none`입니다.

따라서 이미지와 1줄 코멘트가 있는 카드도 카드 아래에서 짧은 코멘트를 확인할 수 있고, 기존 모달에서 이미지 캐러셀과 코멘트 전문을 함께 볼 수 있습니다. 이미지와 3줄 이상의 코멘트가 있으면 카드 아래 코멘트만 숨기며 통합 모달은 유지합니다.

## 계층별 책임

### 화면

`src/presentation/app-controller.js`

- 핵심 규칙의 상태에 맞는 UI 하나만 생성합니다.
- `inline`은 카드 아래 최대 두 개의 시각적 줄로 표시합니다.
- `accordion`은 기본적으로 닫혀 있고 `aria-expanded`로 상태를 노출합니다.
- URL이 있는 아코디언은 펼친 패널에 `링크 열기`를 제공해 새 탭 링크 이동을 유지합니다.
- `modal-only`는 카드 아래 코멘트를 생성하지 않습니다.
- 이미지가 포함된 통합 모달, 캐러셀과 이미지별 삭제 처리는 변경하지 않습니다.

`styles/memos.css`

- 인라인 코멘트를 최대 두 개의 시각적 줄로 제한합니다.
- 아코디언 안의 링크에 키보드 포커스 표시를 제공합니다.

### 처리

카드 생성 처리는 `getCommentDisplayMode`와 `getMemoPreviewKind`의 결과를 조합합니다. 아코디언 대상에는 호버·포커스 미리보기 이벤트를 중복 연결하지 않아 클릭 시 아코디언만 동작합니다. 이미지 대상에는 기존 미리보기 연결을 유지합니다.

### 핵심 규칙

`src/domain/memos/memo-policy.js`

- 줄바꿈 정규화와 줄 수 계산
- 인라인·아코디언·모달 전용 판정
- 이미지·텍스트·통합 미리보기 판정

함수는 DOM, IndexedDB, Firebase, Google Drive에 의존하지 않는 순수 규칙입니다.

### 저장 및 외부 서비스

이번 변경은 메모 스키마, IndexedDB, Firestore, Cloudflare 백업, Google Drive 업로드·삭제·월별 대조를 변경하지 않습니다. 코멘트 원문과 이미지 참조는 기존 형식으로 저장됩니다.

### 의존성 연결 및 앱 시작

새 패키지, 환경변수와 초기화 코드는 없습니다. 화면 컨트롤러가 도메인 규칙을 가져와 사용하는 기존 연결 방향만 유지합니다.

## 테스트

`tests/memo-model.test.js`에서 다음 경계를 검증합니다.

- LF, CRLF, 빈 줄 정규화
- 1줄과 2줄의 인라인 표시
- 링크가 있는 3줄 코멘트의 아코디언 판정
- 이미지가 있는 3줄 코멘트의 카드 미표시와 통합 모달 유지
- 이미지가 있는 1줄 코멘트의 인라인 표시와 통합 모달 유지

변경 후 `npm test`와 `npm run build`를 모두 실행해야 합니다. 수동 검증에서는 PC와 모바일 폭에서 짧은 코멘트, 긴 텍스트 아코디언, 링크 열기, 이미지 캐러셀, 세로 스크롤 및 이미지별 삭제를 확인합니다.

## 확장 시 주의 사항

- 줄 수 기준을 바꿀 때는 `COLLAPSED_COMMENT_LINE_THRESHOLD`와 경계 테스트를 같은 변경에서 수정합니다.
- 화면 계층에 별도의 줄 수 조건을 추가하지 않습니다.
- 이미지가 있는 코멘트를 다시 카드에 표시할 때는 `modal-only`의 단일 책임을 먼저 조정합니다.
- 모달과 캐러셀을 변경할 때 Google Drive 삭제 성공·실패 처리와 카드 표시 정책을 섞지 않습니다.
- 문서와 코드가 다르면 코드를 확인한 뒤 같은 변경에서 문서를 갱신합니다.
